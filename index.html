Ogre VTT is now part of Triplanetary VTT

The ground game moved into the combined app, which plays it exactly as this one did — the same engine, the same boards, the same opponent — and adds what this app never had: a battle builder, online tables, and the war that joins Ogre to Triplanetary.

Open Triplanetary VTT

Taking you there now, keeping whatever was on the address bar — so a ?battle= link from a campaign opens the same landing on arrival. Pick Ogre on the start menu for a ground battle on its own. If nothing happens, the button above is the same trip.

The source is at github.com/onlinemph/Triplanetary-VTT. This repository keeps its history and its notes; the ones worth reading now live over there.
